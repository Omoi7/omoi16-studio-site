Le studio d'un créateur de contenu gaming

Studio omoi16 est l'outil que le créateur omoi16 utilise pour transformer ses lives Twitch en vidéos : il prépare les courts extraits (Shorts, Reels, TikTok), les programme et les publie sur ses propres comptes, puis suit leurs statistiques au même endroit.

Production

Repère les meilleurs moments d'un live, les découpe au format vertical et ajoute les sous-titres.

Calendrier

Planifie les publications de la semaine sur YouTube, Instagram et TikTok.

Publication

Publie les vidéos sur les comptes du créateur via les API officielles des plateformes, après son accord explicite.

Statistiques

Rassemble les vues, les abonnés et les objectifs de monétisation des trois plateformes.

Utilisation de TikTok

Studio omoi16 se connecte à TikTok avec Login Kit et utilise la Content Posting API uniquement pour publier les vidéos que le créateur a choisies, sur son propre compte, avec les réglages qu'il sélectionne lui-même (visibilité, commentaires, duo, collage, mention de contenu de marque). Rien n'est publié sans son action.
